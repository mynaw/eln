ELN 管理员账号重置工具（admin reset）
=====================================

用途
----
忘记管理员密码时，双击 `reset_admin.bat` 即可把管理员账户重置。

重置后的管理员账号与密码（明文记录如下）：

    账号：Eln
    密码：ZZU@2026

说明
----
1. 管理员 = 「当前本地账号」，即 ELN 的主账户。重置只改账号名和密码，
   所有实验记录、药剂、附件、子账号数据都保留不动。
2. 如果 ELN 还没有任何账户，本工具会直接创建上述管理员账户。
3. 密码在 accounts.json 里只以不可逆哈希（PBKDF2-HMAC-SHA256 + 随机盐）
   存储，无法从文件反推出明文；本 README 是唯一保留明文记录的地方，
   请妥善保管本文件夹。
4. 重置会同时清除旧的 30 天自动登录会话，重置后需要用新账号重新登录。
5. 子账号（由管理员创建的普通账户）密码同样只存不可逆哈希，
   丢了由管理员在「设置 ▾ → 管理员账号…」里重置，无法找回。

文件
----
* reset_admin.bat  —— 双击运行的重置入口
* reset_admin.py   —— 重置脚本（会先询问确认，输入 y 才执行）
* README.txt       —— 本文件
